# Panorama semanal de dengue en Sonora

Este repositorio se utiliza para coordinar la generación de datos de dengue para realizar un informe semanal dirigido a la población del Estado de Sonora.

Esta es una colaboración por parte de la Coordinación de Análisis y Estadística de la Dirección de Inteligencia e Información en Salud de la Dirección General de Servicios de Salud Pública de Secretaría de Salud Pública de Sonora, y el área de Inteligencia e Información del Servicio Nacional de Salud Pública en el Estado de Sonora.

Para la generación de información, se estará utilizando el lenguaje de programación `R` y `Markdown`, de tal forma que los archivos a utilizar tendrán la extensión `.Rmd`.

En `R` se requerirán mínimamente las librerias `tidyverse`, `sf`, `leaflet` y `leaflet.extras` *(Esta última posiblemente requiera instalarse mediante devtools y su repositorio de github)*
